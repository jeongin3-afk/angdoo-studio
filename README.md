# 앙두 공식 누리집

충청남도 천안시 공방 **앙두**의 공식 첫 화면(랜딩 페이지)입니다.

## 디자인 기준
- 바탕색: 버터리 화이트 `#FFFCEE`
- 글씨색: 다크 초콜릿 `#3D2722`
- 포인트색: 체리 레드 `#8E1825`
- 글꼴: 프리텐다드(본문) · 와구리체(큰 제목) · 학교안심 받아쓰기(소제목·꼬리표) · 나눔손글씨 가람연꽃(손글씨 메모)
- 상징: `assets/angdoo-logo.png` (이모지 대신 사용)

## 구성
- 머리말: 마우스를 올리면 펼쳐지는 메뉴(앙두 이야기 / 하는 일 / 작업실 / 함께하기) + 오른쪽 `내 주문 확인`
- 첫 화면: 슬로건 + 공방 사진, 아래로 흐르는 글띠
1. 앙두 이야기 — 이름에 담긴 이야기, 믿을 수 있는 기록(졸업증·자격증·상장·저작권·상표 — 빨간 점선 칸은 실제 정보로 바꿔주세요)
2. 하는 일 — 제작 · 원데이 클래스 · 기관 출강, 작업 기록 갤러리
3. 작업실 — 제작 고객 전용 3D 시안 확인과 댓글 (체험용 비밀번호 `0739`)
4. 함께하기 — 소품 가게, 블로그·인스타그램(@angdo0)·네이버 예약, 문의서
- 오른쪽 아래 떠 있는 바로가기(인스타 · 예약 · 문의 · 위로)

> 작업실 비밀번호와 문의서는 현재 화면 시연용입니다. 실제 운영 시에는 서버(예: 폼 수신 서비스, 데이터베이스) 연결이 필요해요.

## Vercel 배포
1. Vercel에서 새 프로젝트를 만들고 이 폴더(또는 GitHub 저장소)를 연결합니다.
2. Framework Preset: `Other`, Build Command: 비워두기, Output Directory: `.`

## 가비아 도메인 연결
1. Vercel 프로젝트 → Settings → Domains에서 도메인을 추가합니다.
2. 가비아 DNS 관리에서 아래 레코드를 추가합니다.
   - `A` / 호스트 `@` / 값 `76.76.21.21`
   - `CNAME` / 호스트 `www` / 값 `cname.vercel-dns.com.`
3. 연결되면 HTTPS 인증서가 자동으로 발급됩니다. (Vercel 화면에 다른 값이 안내되면 그 값을 따라주세요.)
